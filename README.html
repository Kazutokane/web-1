Get Your Game Running

Follow these steps for the best experience.

How to Run Grand Theft Auto San Andreas
Windows
01

To avoid errors like "No License" or missing files, disable your antivirus / Windows Defender, then re-extract the files with WinRAR.

02

Install all programs in the Common Redist folder for full compatibility.

03

Navigate to gta_sa.exe and run it as Administrator.

Running as administrator resolves most save-file and permission issues.

Linux/SteamOS
01

Open a terminal in the extracted folder and make the bundled launchers executable:

chmod +x launch_proton.sh launch_wine.sh
02

Run ./launch_proton.sh — it automatically finds GE-Proton, Proton Experimental, or regular Proton from your Steam install. Prefer plain Wine? Use ./launch_wine.sh instead.

If no Proton is found, install GE-Proton or Proton Experimental through Steam or ProtonUp-Qt.

03

Need launch arguments? Edit the LAUNCH_OPTIONS= line at the top of launch_proton.sh.

Do not add %command% — that token only works inside Steam. The launcher runs your options without it.

Verify Your Download

A hash is a digital fingerprint. Matching it against ours confirms your file is complete and untampered.

01

Press Win + R, type powershell, and press Enter.

02

Run the command below — update the path to where you extracted the game.

(e.g. C:\Users\You\Downloads\gta_sa.exe)

Get-FileHash -Path "gta_sa.exe" -Algorithm MD5
03

If the output matches the hash below, your download is intact.

MD5 25405921d1c47747fd01fd0bfe0a05ae
Enable Achievements & Overlay

To unlock achievements and enable the in-game overlay, follow these quick steps:

01

Navigate to your game folder and locate SOVEREIGN.ini.

02

Open SOVEREIGN.ini with a text editor.

Find the line:

Overlay=0

Change it to:

Overlay=1

Save the file after editing.

03

Launch the game and ensure your display mode is set to:

✓ Borderless Windowed or ✓ Windowed

Fullscreen mode disables the overlay entirely.

Tip Restart the game completely after enabling the overlay.
